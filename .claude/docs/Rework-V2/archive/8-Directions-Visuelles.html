Et si on proposait les trois ?

C'est faisable : en V2 toutes les couleurs passent par des variables, donc une ambiance n'est qu'un jeu de valeurs. Ce que ca implique :

Ce que ca apporte
  • Chacun choisit l'ambiance qui lui plait dans Profil > Apparence
  • Aucun cout de code en plus pour les composants : ils lisent les memes variables
  • Les couleurs d'espaces restent celles du createur de l'espace, adaptees a l'ambiance
Ce que ca coute
  • Trois ambiances x clair / sombre = six palettes a verifier (contrastes, etats, graphiques)
  • Une identite moins nette : captures, icone et page d'accueil montrent une seule ambiance
  • Chaque nouveau composant doit etre controle six fois dans la page /design
Ma proposition
  • Une ambiance signature par defaut, qui porte l'identite (icone, accueil, captures)
  • Les deux autres proposees comme ambiances alternatives dans Apparence
  • Polices identiques partout pour simplifier : seules les couleurs changent d'une ambiance a l'autre
