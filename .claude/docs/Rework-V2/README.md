## Ordre de lecture

1. Ce README.
2. `4-Roadmap.md` : la premiere case non cochee est le point de reprise.
3. Le plan de l'etape en cours (C7 : `24-Plan-C7.md` ; `17-Plan-C1.md` a `23-Plan-C6b.md` pour C1 a C6b, termines).
