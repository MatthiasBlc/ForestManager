Ajouter mes recettes à un espace

Maquette C7c.0 (D203, D208). Parcours dans un espace de groupe, « Coloc », sur mobile. En bureau, les mêmes feuilles s'ouvrent en fenêtre centrée. Dans l'écran 3, les cases se cochent pour voir le compteur bouger.

Hors maquette, déjà tranché

  • Tout ou rien : si une recette n'est plus disponible au moment d'ajouter, rien n'est ajouté, la liste se recharge et la sélection garde les recettes encore disponibles.
  • Le bouton reste « Nouvelle recette » dans l'espace perso, sans « Depuis mes recettes ».
  • La palette (Ctrl K) gagne l'action « Ajouter mes recettes » dans un espace de groupe.
