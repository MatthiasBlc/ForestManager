Decisions

Introduites par ces parcours. Statut : voir le journal des decisions.

  • D60 A l'ouverture, l'app reprend le dernier espace et module visites. L'accueil a widgets (E-ACCUEIL) est l'ecran d'entree de l'espace perso.
  • D61 Apres l'inscription, un ecran de bienvenue a 3 choix passables (creer un espace, rejoindre par lien, ajouter une recette). Pas de visite guidee en plusieurs ecrans.
  • D62 Un lien d'invitation montre l'espace (nom, avatar, membres) avant de rejoindre ; il survit a l'inscription ou la connexion ; rejoindre demande un clic de confirmation. Un lien invalide ne montre rien de l'espace.
  • D63 Une seule porte d'entree pour creer une recette (Saisir, Importer un lien, Coller un texte) ; tout import aboutit au meme editeur pre-rempli, champs douteux marques "A verifier".
  • D64 Une suggestion se redige dans l'editeur de recette en "mode suggestion" ; l'auteur l'accepte ou la refuse en entier en V2.0 (pas d'acceptation partielle).
  • D65 Le partage se regle dans une seule feuille a cases (espaces ou la recette est visible) : cocher partage, decocher retire.
  • D66 Un espace en suppression reste visible, grise, dans le rail de son OWNER seulement, avec le compte a rebours et "Restaurer".
  • D67 Mode cuisine : une etape a la fois en grand, boutons Precedente / Suivante, ingredients dans une feuille, ecran maintenu allume.
  • D68 Hors ligne : bandeau permanent "Hors ligne", actions d'ecriture desactivees avec la raison, pas de file d'attente de modifications ; brouillon de recette conserve localement.
  • D69 Echanger deux repas : glisser-deposer en desktop ; sur mobile, ActionMenu "Echanger avec..." puis toucher le repas cible (pas de glisser-deposer tactile, conflit avec le defilement).

Questions (toutes tranchees)

QP1 par D60, QP2 par D61, QP3 par D64, QP4 par D69, QP5 par D84 (l'ecran "Quitter" demande pour chaque recette).

  • QP1 - Ecran d'ouverture(a) dernier espace et module visites (recommande, D60) ; (b) toujours l'accueil a widgets ; (c) toujours l'espace perso.
  • QP2 - Accueil des nouveaux(a) ecran de bienvenue a 3 choix passables (recommande, D61) ; (b) visite guidee en plusieurs etapes ; (c) rien, arrivee directe dans l'espace perso vide.
  • QP3 - Acceptation d'une suggestion(a) en entier seulement en V2.0 (recommande, D64) ; (b) bloc par bloc des la V2.0 ; (c) ligne par ligne.
  • QP4 - Echange de repas sur mobile(a) menu "Echanger avec..." puis toucher la cible (recommande, D69) ; (b) glisser-deposer apres un appui long ; (c) les deux.
  • QP5 - Recette partagee depuis l'espace perso quand on quitte un groupe(a) le partage est retire, la recette reste dans l'espace perso (recommande : c'est le contenu de l'auteur, D18 vise les recettes creees dans le groupe) ; (b) le partage reste, la recette devient modifiable par les moderateurs ; (c) demander a l'auteur au moment du depart.
