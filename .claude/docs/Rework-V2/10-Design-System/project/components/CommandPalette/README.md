# CommandPalette

Recherche globale et raccourcis, ouverte par Ctrl K (ou la loupe sur mobile). Cherche dans les recettes, ingredients, membres et espaces auxquels on a acces.

- Fleches pour naviguer, Entree pour ouvrir, Echap pour fermer. Resultats groupes par type.
- `groups` : `{ label, items: [{ id, label, icon, hint }] }` ; `onSelect(id)`.
- Sur mobile elle s'ouvre en plein ecran.
