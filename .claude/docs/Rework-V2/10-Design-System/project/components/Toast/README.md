# Toast

Confirmation breve en bas de l'ecran apres une action : "Recette enregistree". Disparait apres 4 secondes.

- `tone` : neutre (accent), `success`, `warning`, `danger`. Une action d'annulation possible (`actionLabel`, `onAction`) pour les suppressions.
- Le texte dit ce qui s'est passe, au participe passe. Pas de toast pour une erreur de formulaire : l'erreur va sous le champ.
