# MealSlot

Un repas dans la grille du planning : recette (fond `accent-soft`), texte libre, vide (pointille, "Ajouter un repas") ou desactive (on ne mange pas ensemble).

- `locked` : cadenas, la generation ne le remplace pas. `servings` : portions si differentes du defaut.
- Toucher : editer le repas (Sheet). Appui long : actions (echanger, verrouiller, remplacer, vider).
- Sur mobile, le planning s'affiche jour par jour ; en desktop, en grille jours x repas.
