# Icon

Icones au trait (grille 24, trait 2, extremites arrondies), heritant de la couleur du texte.

- Dans l'application : **lucide-react**, avec les memes noms. Les dessins de cet apercu sont des remplacements dans le meme esprit, pas les fichiers Lucide.
- 20px dans les boutons et la navigation, 16px dans les puces et les repas, 28px dans les etats vides.
- `label` seulement si l'icone porte seule un sens (sinon decorative, masquee aux lecteurs d'ecran).
