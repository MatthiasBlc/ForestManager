# TintPicker

Nuancier des 5 teintes d'espace de l'ambiance courante (D96) : creation et reglages d'un espace.

- Une pastille ronde de 44px par teinte, coche sur la teinte choisie, nom de la teinte en libelle accessible (`names`).
- La valeur est le **numero** de teinte (1 a 5) : il reste le meme quand l'utilisateur change d'ambiance.
