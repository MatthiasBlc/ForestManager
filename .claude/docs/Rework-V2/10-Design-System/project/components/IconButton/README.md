# IconButton

Bouton carre de 44px avec une seule icone. `label` est obligatoire : il devient l'`aria-label` et l'infobulle.

- `count` affiche une pastille (notifications non lues), plafonnee a 99+.
- `outline` : bordure `line-strong` sur fond `surface-raised`, pour un bouton isole sur une image ou une carte.
- A utiliser pour : fermer, rechercher, notifications, menu "..." d'une carte.
