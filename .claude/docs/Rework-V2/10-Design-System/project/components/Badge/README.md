# Badge

Etiquette d'etat, non cliquable. Toujours un mot, jamais une couleur seule.

- `tone` : `neutral`, `accent` (actif dans l'espace), `second` (Base, Composee : recettes liees), `success`, `warning` (Beta, Original modifie, Hors ligne), `danger`.
- Exemples reels : "Base", "Composee", "Adaptee", "Beta", "Original modifie", "Brouillon".
