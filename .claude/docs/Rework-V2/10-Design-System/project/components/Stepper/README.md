# Stepper

Choisir un petit nombre : portions d'une recette ou d'un repas. Boutons -/+ de 44px, valeur annoncee aux lecteurs d'ecran.

- `min` / `max` (1 a 24 par defaut), `unit` ("pers.") ou `format(v)` pour un libelle sur mesure.
- Changer les portions recalcule les quantites en direct, sans enregistrer la recette.
