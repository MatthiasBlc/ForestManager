# SpaceSwitcher

Changer d'espace **sur mobile** (D130) : l'espace courant est un bouton de la TopBar (`space`, `onSpace`) qui ouvre cette feuille. Remplace la bande d'espaces en haut de l'ecran.

- Ordre du rail : espace perso, separateur, groupes, puis "Creer ou rejoindre un espace".
- Chaque ligne : icone de l'espace (avatar ou initiales sur sa teinte), nom, precision (`hint`, ex. "6 membres"), badge "Nouveau" s'il y a des nouveautes, coche sur l'espace courant.
- Un espace en suppression (`deleting`) est grise avec "Suppression dans n j" (D66).
- A partir de 768px, le rail vertical prend le relais : le bouton d'espace de la TopBar disparait.
