# PullToRefresh

**Tirer pour rafraichir** une liste quand on est tout en haut : au-dela de 64px, `onRefresh` est appele (une promesse) et un indicateur tourne jusqu'a sa fin.

- Pour les listes de recettes, les notifications et le planning, en particulier dans l'application installee et apres un passage hors ligne.
- Le bouton "Actualiser" du menu reste disponible pour la souris et le clavier.
