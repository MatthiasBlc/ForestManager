# ModuleNav

Barre laterale des modules de l'espace courant, visible a partir de 1024px (en dessous : TabBar). Seuls les modules accordes et actives par l'OWNER apparaissent.

- `spaceName` + `subtitle` (nombre de membres) en tete ; `items` : `{ id, label, icon, badge, badgeTone }`.
- Element actif : fond `accent-soft`, texte `accent-text`.
