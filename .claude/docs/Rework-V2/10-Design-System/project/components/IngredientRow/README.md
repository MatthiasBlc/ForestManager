# IngredientRow

Une ligne d'ingredient : case a cocher (mode cuisine et courses), quantite en chiffres tabulaires, nom.

- `quantity` (nombre, deja mis a l'echelle des portions), `unit`, `name`. Les quantites s'affichent avec une virgule et au plus une decimale.
- Toucher la ligne coche l'ingredient (barre le nom) : sert a suivre ce qui est deja sorti ou achete.
