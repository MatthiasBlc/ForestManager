Ce qui change sous le capot

  • Familles : table TagFamily (globale ou d'espace, nom, position) et Tag.familyId facultatif ; familles globales dans l'admin, familles d'espace par les modérateurs.
  • La liste des tags d'un espace renvoie le nombre de recettes par tag ; le filtre combine OU dans une famille et ET entre familles.
  • Un seul composant de choix de tags (filtres, éditeur, fiche, planning, « Depuis mes recettes ») remplace les quatre actuels.
  • Création, renommage, fusion et suppression des tags d'espace : les routes existent déjà, il manque les écrans.
